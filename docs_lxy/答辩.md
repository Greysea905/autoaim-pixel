- 一阶段
    - 一阶段流程介绍；一阶段tree
    - camera/相机取流
    - 标定：相机内参/外参、重投影误差
    - detect/
        - 装甲板识别：模型1：bbox 装甲板识别（半监督，用实拍）
        - 装甲板分类：模型2：装甲板分类（自己制作数据集）
        - 灯条匹配：ROI 单个灯条筛选思路；灯条匹配思路
    - PnP 解算（armor_solve，属一阶段，此处作衔接）
        - SOLVEPNP_IPPE + 重投影误差拒离群
        - 坐标变换链：相机系 → 云台系 → 世界系
        - 法向 yaw：optimizeArmorYaw 搜索（锚定云台朝向+π，±70° 内取重投影误差最小）
    - 决策和算法：
        - 增强侧向板的识别：
            - 装甲板识别能力：实拍取流，手动标注侧向板，半监督学习
            - 灯条匹配：红蓝分别设置不同的灰度阈值
        - 远处灯条角点不稳定：
            - 问题分析：对红蓝灯条灰度梯度可视化（同时发现红色灯条灰度还是亮度不如蓝色稳定）
            - 优化：灰度梯度，亚像素做法：沿灯条轴线取灰度剖面 → 找梯度最大的过渡点 → 抛物线拟合到小数像素，比二值轮廓投影极值抗噪声（有没有可视化方法可以证明？）
- 二阶段
    - 二阶段流程介绍；二阶段tree
    - tracker/（EKF 估计器）
        - 预测 predict
            - 状态向量：10 维整车（世界系）[cx,vx,cy,vy,z0,z1,r0,r1,yaw,w]
            - 状态转移方程 f + 状态转移矩阵 F（匀速平移+旋转，无加速度）
            - 可调参数：Q 过程噪声（q_pos/q_yaw/q_z/q_r）；P 状态协方差（预测传播 F·P·Fᵀ+Q，非可调）
            - 算法思路：二重积分离散化（CA→CV）、NIS 自适应 Q（收敛平滑/发散加速）
        - 关联 association
            - greedy 最近邻 + 马氏距离门限（mahalanobis_gate2）
            - 槽位 90° 分离，观测→槽位一一对应
        - 更新 correct
            - 观测向量：4 维混合系 [cam_yaw, cam_pitch, cam_distance, world_normal_yaw]
            - 观测方程 h + 观测矩阵 H（数值雅可比，中心差分）
            - 可调参数：R 测量噪声（sigma_cam_yaw/pitch/cam_distance/world_normal_yaw）；S 新息协方差（H·P·Hᵀ+R，非可调）
            - 算法思路：后两项随距离动态放大（动态 R）、球坐标 R 天然对角
        - 状态机 state machine
            - converge_frames 收敛、diverged/NIS/超时 → reset、stable_stage 锁存
            - 开火判据 = state==Stable

    - planner/（选板 + 弹道 + 前馈）
        - 选板：中心方位角 + 板面正对（实际退化为选最正对的板）
        - 弹道模型：重力+空气阻力，迭代解 beta（发射角）+ flight_time（飞行时间）
        - 前馈预测：lead = latency + bias + flight_time，外推车体状态
        - 角速度前馈：target_yaw_velocity
        - 输出：target_yaw/pitch/vel + fire_allowance
    - 决策和算法（难点/亮点）
        - 整车建模：10 维旋转车体（板轮流转，不能当单目标）
        - 球坐标观测：R 天然对角、光轴锚定
        - 动态 R：后两项随距离线性放大
        - 半径/高度差物理常数：跨 reset 保留（半径从预设重收敛防塌缩）
        - 数值雅可比：免手推、角度维 wrapPi 差分
